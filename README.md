## 🛠️ Upload Instructions (Summary)

1. Go to **WordPress Admin** (`riskverifier.com/wp-admin`)
2. Navigate to **Appearance > Themes > Add New > Upload Theme**
3. Choose `riskverifier-theme.zip` and click **Install Now**
4. Click **Activate**
